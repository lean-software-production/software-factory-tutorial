## Goal

Implement a truthful, durable server lifecycle for active accepted editors and completed editor history.

## Work

- Add a distinct public status for active accepted editors; reserve completed/unlocked for completed history.
- Allow only accepted editor attempts to be superseded while their block remains active. Keep accepted terminal and reflection attempts immutable.
- Keep monotonic revision and stale-attempt protections.
- Require the current editor attempt to be accepted before `completeBlock` is eligible. A newer reviewing/feedback revision therefore withdraws Continue until accepted again, while durable authored successor material remains revealed.
- Project active accepted editors with their current revision and `draftText`.
- Project completed editors with the accepted revision, text, success checkpoint, and completed status, including after restart.
- Reject submissions after the block is no longer active.

## Constraints

Do not change terminal/reflection progression. Do not retract timeline events or authored successor material. Preserve editor promotion: the workspace file and completed historical text must match the revision accepted at completion.

## Deliverable

Make the attempt-store and workflow lifecycle tests pass, then commit the narrow server changes and focused test evidence.

# Your job: say it in one line

Below is what a station on an assembly line said about the work it just did.
Compress it to a single line for someone watching the line run.

- **Between 8 and 12 words.** Not a sentence with a full stop; a label.
- Say what changed, concretely. "extracted tokenising into a named helper" tells
  someone what happened; "improved code quality" tells them nothing.
- Start with a verb in the past tense. No leading capital, no trailing period.
- Keep an identifier if it is the point of the change. Drop the reasoning, the
  justification, and anything the station said about its own process.

Emit only that line. No preamble, no quotes, no code fence, no alternatives.

## Goal

Keep an accepted but incomplete editor visible, sticky, and editable.

## Work

- Remove the accepted-editor early return from the activity band; completion alone releases the live surface.
- Derive completion only from authoritative block completion.
- Separate visibility from editability. An active editor stays mounted and editable during editing, review, feedback, and accepted states unless a fatal workbook state disables mutations.
- Present accepted success feedback in the welded feedback bar without replacing the editor.
- Keep exactly one Continue control when the current revision is accepted.
- Preserve CodeMirror identity, focus/cursor, local text, debounce, and stale-response guards across asynchronous acceptance.
- After an accepted editor changes, send the next monotonic revision through the existing quiet-period review lifecycle and reflect withdrawn/restored completion eligibility.

## Constraints

Do not change terminal activity-band behavior. Do not autofocus merely because acceptance arrives. Do not regress fatal-state read-only handling.

## Deliverable

Make the accepted-active browser and activity-band tests pass and commit the focused UI change with test evidence.

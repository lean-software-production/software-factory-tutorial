Here's what I'm thinking.

Each tutorial is presented as a single long flowing page of HTML.

There should be a table of contents always visible in the top-left that shows the learner where they are, which changes as they scroll up and down, and allows them to revisit earlier content or move back to where they are quickly and easily.

We need a way to define different parts of the tutorial: fixed narrative content that is pre-prepared and can be rendered straight into the page, interactive LLM-led parts, parts where the learner can type commands or edit files directly in the page, quizzes to check for understanding.

I'm guessing we can build this around a deterinistic engine that leans on agent(s) when needed.

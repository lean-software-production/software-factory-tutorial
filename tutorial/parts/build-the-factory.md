# Part 2 — Build the factory

Now automate the validation loop into a line that can run, branch, record, and be operated.

1. Join them into an assembly line.
2. Put the validator on a read-only harness.
3. Compose stations, and branch.
4. Take the pause off.
5. Record what the line did.
6. Watch it while it runs.
7. Ask the factory what happened.
8. Talk to a running station.
9. Oversee the orchestrator.

By the end you will be able to name the factory, the line, the stations, and the orchestrator in
files you wrote, and be exact about what is still yours to judge.

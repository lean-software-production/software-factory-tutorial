## The harness

It's often said any software factory needs a seed and a harness. "Harness" is an overloaded term in AI software development since, strictly speaking, vendor tools like Claude Code and Codex are themselves harnesses around the LLMs.

The problem with vendor harnesses is that they're generic. We're here to learn how to build our own custom harnesses.

Birgitta Bockeler's excellent [article on harness engineering](https://martinfowler.com/articles/harness-engineering.html) uses the term "outer harness" or "user harness" to make a distinction with those vendor harnesses.

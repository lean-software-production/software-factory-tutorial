## Goal

Make the desired acceptance/completion lifecycle executable before changing production code.

## Work

Add or invert focused tests in `workbook-attempts.test.ts`, `workbook-block-progression.test.ts`, `activity-band.test.tsx`, and `workbook-ui.test.tsx` for the four states described by the parent Yak.

Preserve explicit regression assertions for terminal/reflection accepted-attempt protection, terminal history, editor focus/cursor, debounce, stale response ordering, fatal state, and no historical submission.

## Deliverable

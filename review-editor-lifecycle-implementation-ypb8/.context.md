- Does acceptance preserve CodeMirror/xterm and WebSocket identity?
- Are focus, cursor, debounce, local text, terminal insertion, fatal state, and activity-band handoff protected by meaningful tests?
- Is either practice surface or its feedback rendered twice?
- Does the terminal completion fence close Enter-to-submission and slow-summarisation races across Continue, scroll, and Tutor-tool completion, and recover safely after rejection?
- Is reflection behavior unchanged?

Run focused tests as needed. Report findings by severity with file and line references. Any material finding must be fixed and re-reviewed before this Yak is done.

## Goal

Keep a completed editor visible as read-only historical evidence beneath its authored block.

## Work

- Add an editor-history render path in the timeline near the existing terminal-history insertion point.
- Render one editor surface seeded with the completed accepted text and `contenteditable="false"`.
- Keep completed success feedback attached to that surface.
- Ensure completion removes the editor from `.current-activity-band`, cancels pending submissions, and creates no duplicate surface.
- Historical editors must not autofocus, schedule review, publish local revisions, or reactivate when reread.
- Preserve the same result after browser/server restart.

## Constraints

Use the existing editor visual language where practical. Do not turn historical editors back into active block targets. Keep terminal history unchanged.

## Deliverable

Make completed-history component, workflow restart, and no-submission tests pass. Commit the implementation and focused test evidence.

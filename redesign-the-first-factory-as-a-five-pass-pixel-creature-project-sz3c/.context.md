Intended learner experience:
1. Pass 1 creates and commits a plan of exactly four similarly sized, independently testable implementation tasks, then stops.
2. Pass 2 implements the deterministic seeded pixel-grid generator and terminal/ASCII output.
3. Pass 3 adds creature traits such as bilateral symmetry, eyes, antennae/horns, and configurable size.
4. Pass 4 adds named colour palettes and SVG output.
5. Pass 5 generates a small HTML creature gallery, completes tests, and documents example commands.

The exact task decomposition may be adjusted during curriculum design, but the invariant is one planning pass plus four meaningful work passes. The worker prompt must require exactly one task per pass and then stop; it must not continue through the plan. Each useful pass updates plan.md and commits to the session-local repository. Verification-only/no-op work must not create empty commits.

ralph.sh runs exactly five bounded `pi --no-session -p < prompt.md` invocations and prints explicit, readable `Pass N/5` boundaries before each invocation. The learner should be able to run an example command in the terminal and see a fun creature immediately. The same seed must reproduce the same creature, providing a clear mechanical check across passes.

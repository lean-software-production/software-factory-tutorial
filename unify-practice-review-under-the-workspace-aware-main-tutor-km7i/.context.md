Outcome: replace the terminal-only Practice Coach with one workspace-aware Main Tutor for editor, reflection, chat, and terminal practice. Completed terminal evidence goes directly to the Main Tutor with the bounded terminal transcript and workspace-scoped read-only list_files/read_file tools. Review failures preserve the command evidence and retry assessment rather than asking the learner to repeat successful work. Editor and terminal use one stable, full-width feedback bar that keeps useful feedback visible while a newer review is pending.

Origin: play-test session tutorial/.tutorial/session-20260829-085045-ae54bea5. The first bash ralph.sh run exited 0 and the Practice Coach reported ready, but a Main Tutor failure told the learner to rerun it. Editor feedback also glitched and its loading state replaced useful guidance.

Non-goals: arbitrary shell or nested pi access for the Main Tutor; a terminal-specific faster model before direct-review latency has been measured; curriculum changes.

Done when one successful command can be assessed from its durable evidence and workspace state without a Practice Coach or command rerun; editor and terminal feedback have consistent, non-destructive states; legacy sessions still load; deterministic tests, evals, visual checks, and a failure-injected play-test pass.
